Assistive Feedback Pipeline:
• Spoken Instruction: Web Speech API gives natural spoken navigation instructions.
• Haptics: Pulsed vibration triggered only when supported by browser (Android Chrome).
• iOS Compatibility: Browser vibration is restricted on iOS WebKit. SenseStep uses spoken guidance and directional audio as the primary feedback channel on iPhone.
• Volume Tip: On iPhone, switch the physical Ring/Silent switch to Ring mode and turn up Media Volume.

SENSESTEP DISTANCE CALIBRATION & SETTINGS

Multi-point empirical optical calibration & corridor filtering

Calibration Procedure:

Calibration works best with the same phone, camera, and object type (e.g. Person, Chair, Backpack) you will use during testing.

  1. Place reference object at 0.5m, select 0.5m below, tap Capture.
  2. Move to 1.0m, select 1.0m, tap Capture.
  3. Move to 1.5m, select 1.5m, tap Capture.
  4. Optionally capture 2.0m. Require $\ge 3$ samples for high-quality calibration.
